# Performance Checklist — SMART Repairs

## Daily (2 minutes)
- [ ] Campaign still **Active / delivering** (spend ticking, no rejections).
- [ ] **Replied to every WhatsApp enquiry fast** (minutes, not hours — this is the biggest driver of bookings).
- [ ] Tag each conversation: photo received / quoted / booked / out of area / not proceeding.

## Weekly review
- [ ] **Booked jobs** this week (the real KPI).
- [ ] **Cost per conversation** — stable / down = good; drifting up = watch.
- [ ] **Conversations started** (volume) vs last week.
- [ ] **Photos received rate** — are conversations turning into real quotes?
- [ ] **CTR** (≥2% good, <1% weak), **CPM trend**, **Frequency** (<2.5–3.0 over 7 days).
- [ ] Pause the clear loser; note the winner.
- [ ] Refresh a creative if CTR falling / frequency high.
- [ ] Scale (per `Scaling Strategy.md`) **only if** cost per conversation is healthy **and** you have delivery capacity.

## Monthly
- [ ] Cost per **booked job** (spend ÷ booked jobs) — the number that really matters.
- [ ] Which **repair type** (front bumper / rear bumper / door scratch) books best → make more of that creative.
- [ ] Add a **new before/after** to keep creative fresh (swap in wing mirror, stone chip, alloy, another bumper — see the reusable-system note below).
- [ ] Review placement breakdown; trim any obvious waste (Audience Network / rewarded video) if it's spending with no conversations.

## Reusable system (don't rebuild — refresh)
This campaign is built to **last**. To add a new repair type:
1. Duplicate an existing ad inside the ad set.
2. Swap the **image** (wing mirror / stone chip / alloy / another bumper / another scratch).
3. Lightly adapt the copy from the copy bank (`Primary Text.md` etc.).
4. Keep the **same campaign, ad set, WhatsApp destination and settings** so learning is preserved.

Never start from scratch — swap creatives into the proven structure.

## Red flags → act
- 0 conversations after a fair sample on an ad → pause it.
- Cost per conversation rising 2+ weeks with no creative refresh → new images.
- Frequency > 3 → fatigue → refresh / widen area.
- WhatsApp response times slipping → fix this before spending more.
