# WhatsApp Setup — SMART Repairs

## Objective wiring
- **Objective:** Engagement → **Messages**.
- **Conversion location / messaging app:** **WhatsApp**.
- **Performance goal:** Maximise number of conversations.
- **CTA button:** **Send Message** (opens WhatsApp).

## Pre-filled message
Set the click-to-WhatsApp greeting the ad opens with:
```
Hi Josh, I'd like a quote for a SMART repair. I've attached some photos of the damage.
```
Note: Meta pre-fills the **text** only — the customer still attaches the photos themselves once WhatsApp opens. The wording nudges them to attach photos immediately, which is exactly what you need to quote.

## WhatsApp Business setup for fast, premium response
- **Greeting message (auto):** e.g. *"Thanks for messaging Blue Horizon Detailing — send a couple of clear photos of the damage and your postcode, and Josh will come back to you with an honest assessment."*
- **Away message** for out-of-hours, so no enquiry goes cold.
- **Quick replies** saved for: asking for more photos, asking for postcode/location, confirming it's repairable, arranging a visit.
- **Response speed matters most** — the faster the first reply, the higher the booking rate. Aim to reply within minutes during the day.

## What to ask for in the chat (to qualify + quote)
1. Clear photos of the damage (a few angles + one wider shot).
2. Postcode / town (service-area check).
3. Vehicle make, model, colour.
4. When they'd like it done.

## Lead tagging (for optimisation)
Tag each conversation: **photo received / quoted / booked / out of area / not proceeding.** Report weekly so we optimise toward **booked jobs**, not just message volume.
