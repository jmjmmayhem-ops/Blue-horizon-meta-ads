# Prompt 02 — Draft a New Meta Campaign

Use this prompt to draft a new Blue Horizon Meta campaign ready for Josh to APPROVE / REJECT / EDIT.

---

## Before you start
Read `knowledge/blue-horizon-detailing-master-business-knowledge.md` and `knowledge/meta-ads-operating-rules.md`.

## Prompt

```text
Draft a new Blue Horizon Detailing Meta campaign for: [SERVICE / GOAL / OFFER].
Target area: [AREA, default Rugby + 20 miles / Warwickshire].
Budget guidance: [e.g. £5/day].
Video available? [yes — describe / no].

Use exact service names, pricing, proof and brand voice from the knowledge files.
Keep it premium and local. Do not invent offers, discounts, warranties or proof.
Do not draft SMART repair or alloy refurbishment campaigns unless I have explicitly asked.

Output the full draft in these 14 sections:

1. Campaign objective
2. Campaign name (BH | Meta <Type> | <Angle> | <Area> | <YYYY-MM>)
3. Budget
4. Ad set structure
5. Audience/location targeting
6. Placement recommendation
7. Creative assets needed (prioritise higher-end vehicle proof for static; ask me for the specific video for video ads)
8. Primary text options (give 3)
9. Headline options (give 3)
10. Description options (give 3)
11. CTA
12. Destination recommendation: WhatsApp / Meta lead form / website landing page — and justify it
13. Risks and assumptions
14. APPROVE / REJECT / EDIT
```

## After drafting
- Save the draft to `campaigns/drafts/` using a clear filename, e.g.
  `campaigns/drafts/2026-07-meta-deep-clean-proof-rugby.md`.
- On Josh's instruction, move it to `campaigns/approved/` or `campaigns/rejected/`.
- Never launch — Josh publishes only after explicit APPROVE.
