# Prompt 03 — Weekly Meta Optimisation Report

Use this prompt every week to review Blue Horizon Meta performance and recommend changes.

---

## Before you start
Read `knowledge/blue-horizon-detailing-master-business-knowledge.md` and `knowledge/meta-ads-operating-rules.md`.

## Prompt

```text
Produce the weekly Blue Horizon Meta Ads optimisation report for the last 7 days
([START DATE] to [END DATE]) using the data I provide (pasted or connected account).

Break down:
1. Spend.
2. Reach and frequency (flag creative fatigue).
3. CTR and CPC.
4. Leads / messages.
5. Cost per lead.
6. Booked jobs if known.
7. Lead quality if known.
8. Best campaign / ad set / ad.
9. Worst campaign / ad set / ad.
10. Best service angle.
11. Best destination (lead form vs WhatsApp vs website vs landing page).
12. Wasted spend.
13. Creative fatigue and hook performance.
14. Comment / message sentiment.
15. Landing page or form completion issues.
16. Budget recommendation.
17. Exact changes to make.

Constraints:
- Real services, pricing, areas and proof only.
- Premium, local positioning. No cheap/budget angles.
- No SMART / alloy unless Josh has explicitly asked.
- Recommend only — make no live changes.

Present every recommendation as:

RECOMMENDATION:
WHY:
RISK:
EXACT CHANGE:
STATUS: APPROVE / REJECT / EDIT
```

## After the report
- Save it to `reports/weekly/` as `YYYY-MM-DD-weekly-meta-report.md`.
- Carry approved changes into the live account only after Josh approves, and into Prompt 02 for any new creative/campaign drafts.
