# Prompt 04 — Meta Creative Brief

Use this prompt to produce a creative brief for a Blue Horizon Meta ad (static, before/after, carousel, or video).

---

## Before you start
Read `knowledge/blue-horizon-detailing-master-business-knowledge.md` and `knowledge/meta-ads-operating-rules.md`.

## Prompt

```text
Create a Meta creative brief for Blue Horizon Detailing.

Service / angle: [e.g. Deep Clean transformation / Paint correction gloss / Ceramic water beading / New car protection / Prestige proof / Mobile convenience].
Format: [static image / before-after / carousel / short vertical video / reel].
If video: describe the footage Josh has (vehicle, service shown, transformation, length). If unknown, ASK me for: hook, vehicle, service, transformation, desired CTA.
Target area: [default Rugby + 20 miles / Warwickshire].

Produce:
1. Objective of this creative.
2. Target audience and the feeling we want to trigger.
3. Recommended proof asset(s) — prioritise higher-end vehicles for static/search-style ads (Lamborghini, Rolls-Royce, Bentley, Range Rover, Defender, Porsche, BMW, Mercedes, Audi RS/AMG, Tesla).
4. Hook / first 3 seconds (for video) or main visual (for static).
5. On-screen / caption text beats.
6. Primary text options (3).
7. Headline options (3).
8. CTA.
9. Recommended destination and why (WhatsApp / Meta lead form / website / landing page).
10. Shot list or asset list Josh needs to supply.
11. Risks and assumptions.

Constraints:
- Use exact service names, pricing and proof from the knowledge files.
- Premium, local, results-led tone. No cheap/budget/hype language.
- Review proof only as 4.8-star Google rating / 50+ Google reviews. No invented quotes.
- No SMART / alloy creative unless Josh has explicitly asked.

End with: APPROVE / REJECT / EDIT.
```

## After the brief
- If it leads to a full campaign, feed it into Prompt 02 and save the draft to `campaigns/drafts/`.
- List any missing assets clearly so Josh can supply photos/video.
